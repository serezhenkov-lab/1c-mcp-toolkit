# Управление опасными операциями через MCP

Команда `set_approval_mode` переключает существующее поле «Опасные операции» в текущем сеансе внешней обработки Toolkit:

```json
{"mode":"session_allow"}
```

Поддерживаются ровно три значения: `deny` — запрещать; `ask` — спрашивать каждый раз; `session_allow` — разрешить всё в текущем сеансе. Для возврата подтверждений вызовите ту же команду с `{"mode":"ask"}`.

Команда доступна во встроенном MCP, по `POST /api/set_approval_mode` и через существующий proxy с выбором канала. Используется обычная авторизация транспорта. Дополнительного подтверждения самого переключения нет. Ответ:

```json
{"success":true,"data":{"mode":"session_allow","previous_mode":"ask","scope":"toolkit_session"}}
```

Режим общий для всех клиентов этого экземпляра обработки. `session_allow` сбрасывается при отключении, закрытии, перезапуске и смене базы/пользователя; в настройки сохраняется `ask`. Права 1С и платформенная «Защита от опасных действий» остаются отдельными механизмами.

Изменение режима отзывает прежнее поколение разрешений тем же обработчиком, что поле формы. Повтор уже установленного значения ничего не меняет. Команда не повторяет ожидающие операции и не останавливает исполняющиеся. Неизвестный режим, неверный тип и лишние параметры отклоняются до переключения. Нового параметра запуска нет.

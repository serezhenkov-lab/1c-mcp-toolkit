## Существующие объекты

| Проверка | Объект и действие |
| --- | --- |
| Раздел и меню | Подсистема «Проверка интерфейса» (`МВП`) объединяет штатные объекты |
| Справочник | Номенклатура: стандартные список, создание, наименование, запись и повторное открытие |
| Число и дата | Приходная накладная: `СуммаПоДокументу`, стандартная `Дата`; сохранять без проведения |
| Таблица и выбор ссылки | `ПриходнаяНакладная.СписокНоменклатуры`: Номенклатура, Количество, Цена, Сумма |
| Обработка | Заполнение графика: существующая управляемая форма, период, ВыходныеДни, команда Заполнить |
| Регистр | ГрафикиРаботы: измерение Дата и ресурс Значение; дополнительно доступны КурсыВалют и другие штатные регистры |
| Настройки | Автосохранение периода и выходных дней формы ЗаполнениеГрафика; стандартная настройка списка с вкладками |

Формы консоли запросов обычные, форма заполнения графика управляемая. Доступность штатного окна настроек в тестируемом клиенте проверять фактически; при ограничении сначала фиксировать результат, затем добавлять только недостающую управляемую форму. Дублирующую обработку заранее не создавать.

Перед выполнением заполнения графика выбрать ограниченный тестовый период, проверить существующие записи и предусмотреть восстановление: штатная обработка записывает регистр. Для проверки меню и полей достаточно открыть форму и прочитать/изменить значения без выполнения обработки. Тестовые документы не проводить; созданные записи учитывать по точным ссылкам и удалять адресно.

## Оставленные недостающие примеры

В исходной каркасной конфигурации нет отчётов и констант. Поэтому оставлены `МВПОтчет` и `МВППараметр`. Константа использует автоматически создаваемую платформой форму `Константа.МВППараметр.ФормаКонстант`; отдельная общая форма удалена как лишняя. В отчёте есть число Параметр, флажок Подробно, однозначный список Вариант, команда Сформировать и доступный текст Результат.

В существующую форму `ЗаполнениеГрафика` добавлены только два поля дат, связанные с `ВыборПериода.StartDate/EndDate`: исходное составное поле не принимает обычный текст. Бизнес-код обработки не изменён. Конфигуратор проверил привязки, живой клиент подтвердил ввод, запуск обработки и сохранение настроек. Конец периода нормализуется платформой до конца дня; точный readback сообщает расхождение времени, если передана полночь. Для точного ввода конца дня передавать `YYYY-MM-DDT23:59:59`.

Роль `МВППолныеПрава` нужна созданному ранее пользователю MVPTester: в исходной конфигурации ролей не было. Подсистема `МВП` нужна для организации раздела. Новые справочники, документы, регистры и обработки не требуются.

# http-mvp-carcass-85 Specification

## Purpose
Подтверждённое поведение внешней обработки Toolkit при работе с командами раздела и табличной частью накладной через встроенный HTTP/MCP на каркасной файловой базе 8.5.1.1529. Границы и результаты прогонов: [первичный MVP](../../changes/upravlenie-test-klientom/http-mvp-verification.md), [таблицы и меню](../../../docs/table-menu-carcass-85.md).

## Requirements

### Requirement: Команды через встроенный HTTP
На каркасном стенде Toolkit SHALL предоставлять команды раздела и командных панелей через встроенный MCP внешней обработки.

#### Scenario: Отчёт в разделе
- **WHEN** клиент вызывает команду отчёта в разделе «Проверка интерфейса»
- **THEN** открывается отчёт; наличие вложенной команды не подтверждает раскрытие группы «Отчеты».

### Requirement: Табличная часть приходной накладной
Toolkit SHALL поддерживать read, find, select, add, fill и delete для строк табличной части проверенной накладной.

#### Scenario: Число и отображение
- **WHEN** при добавлении строки передана числовая цена 3
- **THEN** проверяется числовое равенство и возвращается отображаемое значение «3,00».

#### Scenario: Безопасный выбор строки
- **WHEN** отбор для удаления совпадает с двумя строками
- **THEN** возвращается ambiguous_target без удаления; по уникальному сочетанию количества и цены удаляется одна строка.

#### Scenario: Снимок строк
- **WHEN** запрошена вторая страница снимка
- **THEN** возвращается продолжение; ID предыдущего снимка после изменения отклоняется как stale_target.

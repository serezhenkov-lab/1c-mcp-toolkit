# set_approval_mode — проверка 17.11.2026

По уточнению пользователя реализована MCP-команда `set_approval_mode` с обязательным `mode=deny/ask/session_allow`. Она переключает существующее поле через `РежимПодтвержденияПриИзменении`, обновляет поколение разрешений и сохраняет прежнюю политику deny/ask. Повтор текущего режима ничего не меняет. Нового режима и параметра запуска нет. [Контракт](../../../docs/approval-control.md).

Встроенные MCP и REST обрабатывают команду в клиенте EPF до обычного dispatch; proxy передаёт её выбранному каналу, обработчик формы принимает до серверного исполнения. Действует существующая авторизация транспорта. Команда не требует подтверждения самой себя и не исполняет ожидающие операции.

# TASK-015/5.1 — доступная часть без клиентского адаптера

13.11.2026. Проверены текущие исходники и выполнен свежий стендовый прогон на 8.5.1.1529. **5.1 остаётся открытым.** Новая производственная реализация не добавлялась: доступная без независимой идентичности диагностическая часть уже реализована при работе над 4.1.

## Подтверждённая граница

`КандидатыВыделенныхСтрокUI` в форме менеджера читает существующее выделение через `ПолучитьВыделенныеСтроки()`, сопоставляет технические имена колонок с однозначными заголовками API и фильтрует полученные описания. Одинаковые описания сохраняются отдельными кандидатами. Ответ указывает `scope=selected_rows`, `complete=false`, `identity_confirmed=false`; курсор и выделение этот помощник не изменяет. Ограничены число строк (500), длина текста и размер ответа. Это диагностические кандидаты, а не адресуемые row_id и не доказательство отсутствия искомой строки во всей таблице.

| Часть 5.1 | Результат без адаптера |
| --- | --- |
| Прочитать уже выделенные строки | Реализовано внутренним помощником, повторно проверено |
| Отфильтровать прочитанные описания по значениям | Реализовано; одинаковые кандидаты не объединяются |
| Указать неполноту и отсутствие навигации | Реализовано и проверено |
| Подтвердить независимую идентичность и актуальность позиции | Не подтверждено; текст и номер позиции недостаточны |
| Найти строку во всей таблице / подтвердить отсутствие | Не реализовано; выделение не представляет всю таблицу |
| Выбрать однозначную актуальную строку | Не реализовано без независимой идентичности; имеющийся путь отказывает без мутации |
| Обход с разрешённой навигацией и доказанным восстановлением курсора | Не реализовано; разрешение навигации само по себе не даёт идентичности |
| Инвалидация позиции при сортировке | Приёмка не выполнена; позиционные цели не выдаются как подтверждённые |

Ограничение согласуется с ранее сохранённым [исследованием идентичности](row-identity-851.md): обычный внешний API возвращает описания, а выделение не является устойчивым маркером строки. Нативные ID подтверждены только внутри исследовательской фикстуры; клиентский адаптер по решению пользователя не внедряется. Это не доказательство принципиальной невозможности другого решения.

Прогон успешно завершён штатным harness.

Для 5.1 существенны `selection_table`, `selection_no_navigation`, `row_description_not_stable`, `table_duplicates`, `table_distinct_candidates`, `table_no_mutation`. Число 31 относится ко всему набору ввода, **не к 31 новой проверке таблиц**. В этом прогоне не проверялись сортировка, смена строки между чтениями, полный обход динамического списка и восстановление курсора. Предыдущие проверки этих аспектов не объявляются новым прогоном. Публичные `test_table`-маршруты не подключены. Производственный BSL не менялся, поэтому отдельный BSL LS и полная регрессия не запускались.

## Статус

Для продолжения полной реализации требуется подтверждённый способ связывать строку с актуальным снимком независимо от текстов. Существующее ограниченное чтение можно использовать как диагностику; выдавать по нему подтверждённый выбор или свежий row_id нельзя. Контракт не упрощён. 5.1, 4.4, 4.1 и 1.4 остаются открытыми, рабочая установка не обновлена, к Открыть() не возвращались.

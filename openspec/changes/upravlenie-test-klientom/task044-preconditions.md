# TASK-014/4.4 — недоступные предусловия нажатия группы

**4.4 остаётся открытым, производственная реализация не добавлена.** На 8.5.1.1529 подтверждено ограничение API менеджера, необходимое для исполнения текущего контракта без клиентского адаптера.

## Требование и проблема

UI-07 и design.md требуют click_group только для группы-карточки с гиперссылкой, проверку до действия и отказ обычной группе. Наличие метода Нажать() и отсутствие исключения не доказывают эти условия.

Каталог API ТестируемаяГруппаФормы содержит свойства Имя, ТекстЗаголовка, Вид; методов чтения ShowAsCard/Hyperlink не содержит. Runtime подтвердил, что русские и английские имена ОтображатьКакКарточку/ShowAsCard и Гиперссылка/Hyperlink недоступны: «Поле объекта не обнаружено».

## Стендовый результат

Новые внешние EPF из `.local/task044/run1`, конфигурация не менялась. Исторический положительный тест нажатия в интерфейсе Версия8_5 остаётся в capabilities-851.md; новый тест не объявляется проверкой другой среды.

У всех трёх групп одинаковый обработчик Click, увеличивающий счётчик. Таким образом, отрицательный контроль обычной группы не основан на отсутствии обработчика. Сохранено 18 диагностических наблюдений: 3 набора доступных свойств, 12 попыток чтения отсутствующих свойств и 3 вызова. Это **не 18 приёмочных проверок реализации 4.4**. Повторного нажатия в пробе нет; производственные сценарии отказа версии и сбоя диагностики click_group пока не реализованы и не проверены.

Артефакты: [наблюдения](evidence/task044-properties.json), [проверка выводов](evidence/task044-verification.json), [SHA-256](evidence/task044-sha256.json). Воспроизводимая подготовка — `tests/test_client/group_probe`. Платформенные ThinClient/Server/HandlersExistence и сборка обеих EPF успешны; Python py_compile успешен. Производственные модули основной формы и менеджера совпадают по SHA-256 с итогом 4.3. BSL LS и регрессия Toolkit повторно не запускались, поскольку производственный код не менялся.

## Решение в текущих границах

Проверку по префиксу версии, имени группы, её заголовку или отсутствию исключения нельзя подменять доказательством карточки-гиперссылки. XML формы фиксирует исходные настройки, но не гарантирует текущее состояние при программном изменении свойств. Предварительное пробное нажатие само является действием и не удовлетворяет проверке до мутации.

Для завершения требуется отдельный разрешённый способ получать эти признаки из живой формы либо согласованное изменение контракта. Пользователь запретил внедрение клиентского адаптера; этот запрет сохранён. Непроверенное предположение или отключение возможности не приняты за завершение пункта. 4.1 и 1.4 также открыты, к Открыть() не возвращались; рабочая установка не обновлена.

## Остаток и порядок продолжения

1. Для runtime-приёмки клиент-серверной среды нужен отдельный доступный и подготовленный стенд. RDP/server_host/Linux/реальные ACL и оставшиеся гонки также не подтверждены локальными инъекциями.
2. Табличный выбор/заполнение/удаление и полное чтение зависят от независимой идентичности. Наблюдатель отложен; безопасные отказы не закрывают положительные сценарии.
3. Анонимизация отложена. Исследования Открыть() и карточки не возобновлялись, соответствующие требования остаются.
4. Для 7.5 остаются другие формы/БСП и полная отрицательная матрица. Основной T43_Required, модальный номер и принятые снимки повторно не назначаются без изменения кода или нового сбоя.
5. В общем lifecycle — legacy/unclaimed file recovery и остальные среды; в расширениях — свежий платформенный uilog, доверенный контекст runner, восстановление run/step, продуктовые сборщики diff/показателей. Это самостоятельный остаток, не основание объявить v1 принятым.

[Единый остаток](remaining-after-task022.md) — точка выбора следующей работы. Из независимых задач без наблюдателя доступен свежий uilog → draft → ревью (остаток 11.2); его исполнение этой документальной сверкой не запускалось.

# TASK-013/3.5 — идентичность строк

Из expect row удалено подтверждение идентичности по равенству отображаемых текстов до/после чтения. ПолучитьТекущуюСтроку возвращает описание, а не независимый идентификатор. Текущий адаптер не умеет подтверждать неизменность физической строки без навигации, поэтому equals возвращает incomplete_search, verification=not_confirmed, matched=false. actual.identity сообщает unavailable/stable_row_identity_unavailable, values_verified=false. values — диагностические чтения, их принадлежность одной строке не гарантируется; found=false не доказывает отсутствие. not_equals по-прежнему не подтверждает отсутствие во всей таблице. Навигация и мутация в expect не добавлены. Диагностика ошибки ограничена 1 МиБ.

Это реализация обязательного отказа UI-08 при недоказанной идентичности, а не реализация стабильных row_id. Полноценное адресное изменение строк и find относятся к TASK-015; текстовые описания нельзя использовать как идентификатор и там.

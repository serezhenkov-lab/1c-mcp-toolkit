# TASK-021 — editing поля табличного документа

17.11.2026. Положительно проверен нативный путь поля табличного документа, сохранённый в [предыдущем исправлении](scenario-editing.md). Пункты TASK-021 не закрывались, 13/42. Рабочая установка не обновлялась, клиентский наблюдатель не подключён.

## Что проверено

В отдельной Action Fixture создан реквизит ТабДок типа ТабличныйДокумент и поле вида ПолеТабличногоДокумента. Редактирование=Истина, Защита=Ложь, ТолькоПросмотр=Ложь; ячейка R1C1 содержит SHEET_EDITING_UNCHANGED. Разрешение редактировать само по себе не означает активный редактор: исходное editing=false.

Тестовая проба менеджера использует документированный API 8.5: УстановитьТекущуюОбласть("R1C1"), НачатьРедактированиеТекущейОбласти(), ТекущийРежимРедактирование(), ЗакончитьРедактированиеТекущейОбласти(Истина). Новое содержимое не вводится, завершение — с отменой. Весь цикл: false → true → false. Текст области до/после совпал; element_id поля в трёх inspect-снимках одинаков. Идентичность строк таблицы из текста не выводится: проверяется конкретное поле и фиксированная область табличного документа.

Каждое состояние независимо прочитано нативной пробой, test_inspect/tree и продуктовым ScenarioContextProvider/runner через test_expect/editing. Пробы существуют только в тестовой копии менеджера, не в тестируемом клиенте и не в продуктовой EPF. Продуктовый BSL этого этапа не менялся.

## Продуктовые сценарии

Добавлена отдельная capability `test_expect:editing:field_state:none`, реестр содержит 24 ключа на файловых HTTP/file/embedded 8.5.1.1529. Для selector.type=table сохраняется прежний table_state, без повторной runtime-проверки уже принятой таблицы.

Для type=field preflight подтверждает поддержанную операцию, политику и параметры; это не доказательство поддержки любого вида поля. Перед отправкой guard требует полного свежего дерева, однозначного селектора и известного Boolean editing. Обычное поле ввода имеет editing=null и остаётся заблокированным guard: status=blocked, dispatch_count=0, runtime_precondition_failed. Untyped-селектор не получает field_state. Неподдержанное значение не становится false, фокус не используется как замена editing.

Это наблюдение состояния, не разрешение редактирования содержимого, работы с ячейками или табличных мутаций. Политика grant в стенде содержит только конкретные ожидания состояния. Прямой UI API не изменён; добавлено отображение вида цели в capability_key.

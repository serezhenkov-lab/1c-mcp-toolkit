# TASK-021 — editing: тип цели и подтверждённый режим таблицы

17.11.2026. Причина property_read_failed локализована и исправлена в типизации чтения. Подтверждённые прежние runtime-сценарии не повторялись. Пункты TASK-021 не закрывались, 13/42.

## Подтверждённая причина

СвойствоUI вызывала ТекущийРежимРедактирование() для любого узла inspect. В справке установленной 8.5 через MCP bsl-context этот метод описан для ТестируемаяТаблицаФормы и расширения тестируемого поля формы для табличного документа. В расширении обычного поля ввода его нет.

Нативная проба на 8.5.1.1529 для обычного поля Текст воспроизвела точное исключение: «Ошибка при вызове метода контекста (ТекущийРежимРедактирование): Неподходящий тип элемента управления для вызванного действия». Это не потеря соединения и не проблема lifecycle. Общий catch скрывал отличие неподдержанного вида элемента от ошибки чтения.

Альтернативы сверены со справкой: ПолучитьТекстРедактирования() возвращает строку, а не признак режима; документированная ошибка вне редактирования относится к полю-колонке таблицы. ПолучитьТекущийЭлемент() описывает фокус. Ни текст, ни фокус не подменяют булево editing обычного поля ввода. Клиентский наблюдатель не добавлялся.

## Изменения

- В manager BSL перед CurrentModeIsEdit проверяются тип и вид: таблица либо поле табличного документа. Для других типов результат available=false/value=Неопределено/reason=property_not_supported_for_type. Для ошибки действительно поддержанного API сохраняется property_read_failed.
- Inspect обычного поля сохраняет editing=null и явную unavailable_reasons.editing. Прямой test_expect editing=false возвращает value_unavailable, а не успех.
- Добавлена только `test_expect:editing:table_state:none`: точный selector.type=table, полное однозначное дерево, известный Boolean. Реестр теперь содержит 23 ключа на файловых HTTP/file/embedded. Guard использует действующее наблюдение свойства, нативный исполнитель читает состояние ещё раз.
- table_state — состояние всей таблицы, не идентичность строки или редактируемой ячейки. `test_table`, row и выбор по таблице не разрешены этой capability. Field/scalar editing остаётся неподдержанным продуктовым реестром.
- Путь поля табличного документа сохранён по его документированному API; положительная runtime-приёмка этого вида поля и отдельная capability не заявляются. Обобщения поддержки на другие поля нет.

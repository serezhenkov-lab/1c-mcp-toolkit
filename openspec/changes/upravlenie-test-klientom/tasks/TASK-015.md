# 1c-mcp-toolkit / TASK-015 — Таблицы и завершение редактирования строк

## Цель и ожидаемый результат

**Статус 18.11.2026:** шесть операций приняты на штатной табличной части накладной через встроенный HTTP. [Протокол](../../../../docs/table-menu-carcass-85.md) и [актуальный остаток 5.1–5.4](../tasks.md). Предыдущие результаты этой карточки относятся к прежним сборкам.

Выполнять табличный сценарий с однозначной строкой и проверкой применённых значений.

## Требования и сценарии

[UI-05](../specs/test-client-ui/spec.md), все сценарии таблиц; также UI-01 для неоднозначности.

## Границы работы

Чтение, поиск/выбор, добавление, заполнение и удаление. Без обещания полного чтения динамического списка и атомарности составной команды.

## Затрагиваемые объекты и технические указания

Служебная форма и адаптированные табличные функции Answer42. Позиционные цели связывать со снимком; возвращать частичный результат. См. [решение](../design.md) и [исследование](../research.md).

## Зависимости

Завершённый [TASK-013](TASK-013.md), существующие ввод/действия TASK-014. Для полного 5.1 требуется доказанная идентичность из [TASK-019](TASK-019.md); затем 5.1 → 5.2 → 5.3. Остаток 4.1 использует 5.1, поэтому весь TASK-014 не является предпосылкой TASK-015. Пункт 5.4 ждёт также отдельного подтверждения API/эффекта открытия 1.4 и строки/колонки. Подключение к публичным маршрутам выполняется в TASK-016 по мере готовности.

## Критерии приёмки и проверка

Изменённый порядок строк инвалидирует прежнюю позицию. Равные значения не объединяют разные строки и не доказывают конец списка. Навигационное чтение требует явного разрешения и сообщает состояние курсора; незавершённая строка возвращает row_edit_pending без скрытой отмены. После заполнения завершено редактирование и прочитаны значения. При частичной ошибке перечислены выполненные шаги; удаление проверено наблюдением.

## План выполнения

Прогресс хранится только в [tasks.md](../tasks.md#task-15).

- 5.1 Реализовать чтение, поиск и выбор строки с областью поиска и актуальностью снимка; проверить одинаковые строки, неполноту, сортировку, явное разрешение навигации и состояние курсора.
- 5.2 Реализовать добавление, заполнение и удаление с завершением редактирования; проверить значения, удаление и row_edit_pending без автоматической отмены строки.
- 5.3 Обработать частичное заполнение и сбой связи внутри составной операции; проверить список выполненных шагов и отсутствие автоматического повтора/ложного отката.

- 5.4 Реализовать open_cell_value после подтверждения API и идентичности строки/колонки; проверить одинаковые строки, сортировку, частичное позиционирование, открытое окно и unsupported_operation до мутации.

Уточнение 1.4: точный API найден в справке 8.5.1.1529 — Открыть() у тестируемого поля колонки; условия нового поведения: Версия8_5, ссылочное значение, строка вне редактирования. В [пробе](../capabilities-851.md) вызов не открыл форму значения; capability unverified. Реализация 5.4 не должна обходить это ограничение альтернативным открытием.

## Результат и доказательства

19.11.2026: [проверка встроенного HTTP](../http-table-diagnostics-20261119.md#task-015) закрыла 5.2–5.3 на табличной части накладной. Подтверждены сортировка с отказом по прежнему снимку, чтение без навигации, частичный ввод, сохранение активного редактора при `row_edit_pending` и отсутствие повтора при контролируемом завершении клиента после первой ячейки. Для записи по позиции пока отсутствует независимая идентичность.

13.11.2026 в рамках 4.1 пользователь разрешил необходимые части 5.1–5.2. Реализован внутренний помощник чтения уже выделенных строк для диагностики формы выбора: ограниченный охват, сопоставление имён колонок с подтверждёнными заголовками API, сохранение одинаковых кандидатов, отсутствие навигации и запрет выбора без независимой идентичности. [Протокол](../task041-runtime.md).

На этапе 4.1 полные 5.1 и 5.2 не выполнены: устойчивые row_id и полный поиск не реализованы; добавление/заполнение/удаление тогда не подключены. Эти пункты остаются открытыми. Значения текстов не приняты за идентификаторы; публичные test_table-команды не заявляются готовыми.

Продолжение необходимых частей 5.1–5.2: [проверка нативных ID, перестановки, удаления/добавления и очистки](../row-identity-851.md). Это исследовательская фикстура, а не готовые публичные табличные команды; пункты остаются открытыми.

Проверка 5.1 без внедрения адаптера: [доступный охват и свежий прогон](../task051-without-adapter.md). На 8.5.1.1529 повторно подтверждено ограниченное чтение выделения и сохранение одинаковых кандидатов; 31/31 существующего набора ввода. Полный поиск, актуальность позиции после сортировки и выбор строки не подтверждены; 5.1 открыт.

Частичная реализация 5.2: [добавление без заполнения](../task052-partial.md). Внутренний test_table/add выполняет один вызов без values, сообщает состояние редактирования и неподтверждённую идентичность; при уже открытом редакторе — row_edit_pending без отмены. Стенд 8.5.1.1529: 9/9 новых проверок, 31/31 регрессии ввода. Заполнение/удаление и весь 5.2 остаются открытыми.

Частичная реализация 5.3: [частичные результаты добавления](../task053-partial.md). Добавлены состояния add/observe_editing, сохранение неизвестного исхода и выполненных шагов, очистка устаревшего editing, инвалидация UI-целей до мутации. На 8.5.1.1529 — 24/24 проверки отказов (включая реальное завершение собственного клиента) и 10/10 регрессии добавления. Частичное заполнение ячеек не реализовано, полный 5.3 открыт.

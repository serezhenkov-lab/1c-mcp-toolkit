# 1c-mcp-toolkit / TASK-022 — Diff снимков и платформенные показатели

## Цель и ожидаемый результат

Сократить повторное чтение диагностики и измерять стоимость шага в явно заданных границах.

## Требования и сценарии

TE-05/TE-06. Отложенное расширение, не зависимость исходной приёмки. См. [дополнительные требования](../specs/test-client-testing-extensions/spec.md), [UI](../specs/test-client-ui/spec.md), [сеанс](../specs/test-client-session/spec.md) и [интеграция](../specs/test-client-integration/spec.md).

## Границы работы

**16.11.2026 разрешена доступная без наблюдателя часть 12.1 и 12.2.** Сравнение сопоставимых снимков и проверенные показатели; без заявления о полной истории UI или человеческой трудоёмкости по платформенным счётчикам.

## Затрагиваемые объекты и технические указания

Существующие снимки, общий operation_id и артефакты. API показателей проверить на конкретной сборке; не переносить методы доноров как доказанную совместимость. Основание: F-04/F-20 в [реестре](../donor-findings-register.md), [сводный разбор](../donor-synthesis-roadmap.md), [решение](../design.md).

## Зависимости

12.1 — после TASK-018 и стабильной идентичности/coverage снимков; табличный diff также после 5.1. 12.2 — после 11.3 и отдельной проверки платформенного API. Два пункта не зависят друг от друга. Сводная последовательность — [план](../tasks.md).

## Критерии приёмки и проверка

При неполноте нет ложных удалений. У метрик сохранены границы шага/источник/недоступность; вложенные и параллельные интервалы не считаются дважды. Ошибка диагностики не меняет итог действия. До реализации проверить схемы/контракт; при реализации отдельно фиксировать статические проверки, сборку, runtime и приёмку, не расширяя охват старых протоколов.

## План выполнения

Прогресс хранится только в [tasks.md](../tasks.md#task-22).

- 12.1 Добавить diff сопоставимых UI-снимков; проверить session/поколение/идентичность, охват, усечение и отсутствие ложных удалений.
- 12.2 После проверки API добавить показатели вызовов/времени/объёма по исполнению шага; проверить недоступность, вложенные и параллельные интервалы, отсутствие сброса чужих счётчиков.

## Результат и доказательства

Доступная часть 12.1 реализована отдельным модулем `ui_snapshot_diff.py`: diff свойств дерева по зарегистрированным ID с проверкой привязки, корней, coverage и усечения. 12 новых локальных тестов прошли; на отдельной файловой 8.5.1.1529/HTTP proxy подтверждены три проверки на живых снимках и один отрицательный случай с подменой привязки. [Контракт и протокол](../ui-snapshot-diff-partial.md). Полный 12.1 остаётся открытым: нет продуктового сборщика доверенной привязки, табличной идентичности и полной истории UI; Доступная часть 12.2: необязательный сбор показателей в runner, чтение накопленных значений без сброса, диагностика unavailable и запрет суммирования общих счётчиков. API и четыре проверки runner подтверждены на отдельной файловой 8.5.1.1529; 10 новых локальных тестов прошли. [Контракт и протокол](../step-metrics-partial.md). Полный 12.2 остаётся открытым: продуктовый reader, единицы и атрибуция счётчиков не завершены. Рабочая установка не обновлялась.

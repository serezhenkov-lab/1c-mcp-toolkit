## Критерии приёмки и проверка

Неизвестный последний шаг отклоняется до первого действия; параметры проверены целиком. Новый запуск не получает старые результаты, retry одного исполнения не повторяет мутацию. Unknown требует сверки и явных условий продолжения; политика продолжения не меняет результат ошибки. До реализации проверить схемы/контракт; при реализации отдельно фиксировать статические проверки, сборку, runtime и приёмку, не расширяя охват старых протоколов.

# Настройки тест-клиента текущей базы

Из формы удалены «Использовать профиль», «Для запуска требуется пароль», «ID профиля» и «Сохранить профиль». Поля переименованы в «Пользователь» и «Пароль». Порт по умолчанию 1538 находится в сворачиваемых дополнительных настройках.

Пользователь и порт сохраняются при изменении. Пароль остаётся в памяти текущего сеанса, пустой пароль не добавляет аргумент `/P` к запуску. Для новой настройки MCP использует ID `local`, существующий сохранённый ID сохраняет совместимость.

## Проверено 18.11.2026

Через Toolkit MCP на каркасной базе 8.5.1.1529 прочитаны восстановленные `MVPTester`, порт 1538, ID `local` и признак пустого пароля. Через клиентский вызов MCP вызван обработчик изменения порта. Из хранилища повторно прочитано 1539, затем восстановлено 1538. `test_session/start` с `local` и пустым паролем достиг `ready` на 1538. `test_session/stop` завершился успешно. Режим разрешений возвращён в `ask`.

Отдельного прогона с изменением имени пользователя и запуска под пользователем с непустым паролем не было. Размещение и подписи полей проверены по XML формы и сборке, без управления рабочим столом.

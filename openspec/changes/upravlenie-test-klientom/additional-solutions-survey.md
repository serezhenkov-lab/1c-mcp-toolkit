# Дополнительные решения на штатном TestManager/TestClient

Дата: 14.11.2026. Поиск публикаций и документации; установка, анализ BSL и runtime-проверки не выполнялись. Полезность ниже — направления дальнейшего исследования, а не доказательство совместимости с Toolkit.

Продолжение: [анализ исходников Тестера](tester-source-analysis.md). Уточнение по исходникам: ConnectedHost/ConnectedPort присваиваются до Connect и отражают параметры попытки подключения, а не независимо проверенный адрес. Первоначальный обзор ниже основан на документации.

Общий [реестр находок](donor-findings-register.md) объединяет Тестер и последующий анализ исходников Vanessa Automation, TestingTool-3 и CodexTestBridge. Решение о переносе отложено до общего сравнения.

Продолжение по Инфостарту: [доступный код менеджера EPF/ERF, открытый ui-driver и адресный запрос по 1С:Сценарному тестированию](infostart-source-analysis.md). Материалы Инфостарта остаются частью исследования.

15.11.2026 получены выгрузки 1С:Сценарное тестирование и 1С:Тестировщик: [анализ ядра, различий и кандидатов для Toolkit](1c-testing-products-source-analysis.md). Запрос исходников менеджера закрыт.

| Решение | Подтверждено публикацией/документацией | Что изучить для Toolkit |
| --- | --- | --- |
| Тестер | Небольшие обёртки над ТестируемоеПриложение; доступен прямой API. Профиль содержит Computer/Port/ClientID и фактические ConnectedHost/ConnectedPort. Серверный код сценария выполняется в базе Тестера. | Разрешение неоднозначных элементов, работа с таблицами, разделение настроенного и фактического подключения. |
| Тестирование 3.0 (TestingTool-3) | Менеджер сценарного теста записывает действия штатным механизмом; кейсы DDT, библиотеки шагов. | Повторное использование шагов, параметризация, запись и воспроизведение. |
| Vanessa Automation | Документированы таймауты запуска, интервалы попыток, контроль единственного клиента, завершение по PID после ожидания. | Ожидание готовности и диагностика запуска/завершения. Принудительное завершение само по себе не доказывает безопасное владение процессом. |
| Простой менеджер EPF/ERF | Автор приводит полный пример для нескольких конфигураций, запуск, ожидания, обновление и открытие внешней обработки; проверял на 8.3.16. | Варианты диалогов безопасности и закрытия на разных версиях. |
| 1С:Сценарное тестирование 3.0 | Запись и отладка через отдельную обработку в менеджере и тестируемый клиент. | Преобразование записи действий в редактируемый сценарий. Это другой продукт, чем TestingTool-3. |
| CodexTestBridge | По статье штатные TestManager/TestClient, JSON DSL, progress/summary/diagnostics, серверная подготовка и проверка после UI. | Машинная диагностика, последний успешный шаг, readback результата. Заявления автора не проверены на нашем стенде. |

## План приёмки без повторов

- file: сохранённый uilog → явная локальная reviewed-производная → guarded input → readback через ScenarioRunner/общий lifecycle. Это новый маршрут сценария, а не повтор HTTP.
- embedded: авторский сценарий на другой форме Action Fixture, guarded input с целью Флаг → readback → неуспешное наблюдение с continue_observation → пропущенная мутация → успешное последующее наблюдение. Не выдаётся за другой подлинный uilog.
- В каждом новом стенде сверяется неизменность документов и завершение собственных процессов. Прежние unit/runtime-наборы и сборка EPF не повторяются: используется итоговая EPF предыдущего этапа.

Контекст задаёт доверенный harness для фиксированного известного сценария и собственной базы. Кандидатная capability явно помечена как проверяемая в этом прогоне: прохождение preflight само по себе не доказывает работоспособность транспорта/действия. Только успешный runtime результат пополняет доказательства.

## Новый конкретный дефект / неизвестное

На Action Fixture ошибка возникла после успешной активизации и до подтверждения input_text. По исходникам этот участок вызывает Поле.ВвестиТекст; before-confirmed guard уже прошёл. Код connection_lost общий для неожиданного исключения и **не доказывает** разрыв соединения. Исходный текст исключения публичный результат не сохранил; журналы manager/client пусты. Причина не доказана, повторяемость отдельным запуском не проверялась. Ввод автоматически не повторялся. Форма тестовой EPF отличается от нативной T43_Required; прежнее доказательство native-формы не отменено.

Неподтверждённый ввод — самостоятельное препятствие расширенной приёмке форм. Следующее расследование должно сохранять первичное исключение и наблюдение после отказа на изолированном стенде; нельзя объявлять его обычным успешным вводом либо повторять мутацию по unknown. Продуктовый код в этом этапе не менялся.

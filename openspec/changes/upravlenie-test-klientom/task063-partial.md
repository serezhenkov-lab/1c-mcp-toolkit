## Изменения

`КомандаТребуетПодтверждения` основной формы приведена к классификации design.md: start/attach/detach/stop требуют разрешения, status — нет; table/read/find без allow_navigation не требуют разрешения, с навигацией — требуют. Прочие действия таблицы, open/input/action требуют разрешения. Неизвестные действия и некорректные параметры session/table не освобождают от проверки. Прежняя обработка execute_code и старых инструментов сохранена. Классификатор экспортирован для вызова из служебной формы; `ПодготовитьРазрешениеUI` использует его для таблицы, поэтому чтение без навигации не блокируется режимом deny ещё до определения доступной возможности API.

В Python Anonymizer добавлена отдельная ветка для семи test_*, не меняющая обработку прежних инструментов. Группы включены в перечень анонимизируемых инструментов по умолчанию; пользовательские настройки анонимизации сохраняют действие. Новый обход передаёт текстовые листья существующему обработчику, включая словарную обработку. Протокольные ID (request/operation/session/window/element/row/snapshot, cursor/next_cursor), версия, статусы и временные отметки сохраняются как строковые значения. Исключения не распространяются на вложенные объекты целиком; обычное поле id не освобождается от анонимизации.

Обратная обработка test_* восстанавливает токены только в текстовых слотах text/title/equals/list_value и строковом condition.value. Идентификаторы, профиль, action и имена метаданных/колонок/path остаются неизменными, даже если выглядят как зарегистрированный токен. Оба обхода создают новые структуры, не меняя исходный запрос/ответ.

Вложенные поля password/pwd/пароль/connection/connection_string/строкасоединения/authorization/access_token/refresh_token заменяются на `[REDACTED]` до текстовой обработки, в том числе при выключенной обработке ошибок. Это защита **перечисленных полей**, не гарантия обнаружения секрета в произвольной строке ошибки. include_errors=False сохраняет прежний смысл настройки для текста ошибок. Подключение к действующим настройкам и безопасное поведение после разрешения публичного исполнения потребуют сквозной проверки.

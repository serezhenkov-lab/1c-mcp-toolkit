# TASK-021 — страницы формы и наблюдение скрытого содержимого

17.11.2026. Следующий доступный пакет из единого остатка — продуктовый select_page и согласование guard с нативной семантикой страницы. Основание — [внутренняя приёмка 4.2](task042-runtime.md) и текущий ВыполнитьДействиеUI: он проверяет нативные виды Страница/Страницы и текущую видимость/доступность до вызова, затем подтверждает точную текущую страницу. BSL/EPF не менялись.

## Изменение продукта

Добавлен test_action:select_page:scalar:none, реестр содержит **20 ключей** на трёх маршрутах файловой 8.5.1.1529. Это не click группы-карточки: соответствующая capability не добавлена.

Guard по полному свежему дереву сохраняет однозначность и enabled=true. Для select_page требует группу-цель и непосредственного родителя-группу с visible/enabled=true; допускает известное visible=false самой неактивной страницы. Типы «Страница»/«Страницы», не опубликованные в универсальном дереве, проверяет существующий нативный исполнитель непосредственно до изменения. Ни произвольный контейнер, ни кнопка не считаются доказанной страницей по одному имени.

Отдельно разрешено чтение visible=false у найденного доступного элемента через test_expect/visible. Unknown/null остаётся блокировкой. Такое наблюдение не разрешает click скрытой кнопки или ввод в скрытое поле. Прочие мутирующие действия сохраняют требование visible=true; скрытый/недоступный родитель страницы не обходится.

## Приёмка одним этапом

Новая шестишаговая цепочка через отдельный продуктовый CLI:

1. Выбрать вторую, изначально неактивную страницу.
2. Подтвердить visible=true для Метка2.
3. Подтвердить visible=false для Метка1.
4. Вернуться на первую страницу.
5. Подтвердить visible=true для Метка1.
6. Подтвердить visible=false для Метка2.

В HTTP/file общий SQLite lifecycle дополнительно прочитан read-only: ровно два succeeded test_action, test_input/test_open нет. Для embedded сохранены публичные ответы lifecycle. Документы неизменны, собственные процессы завершены. Клиент видим по прежнему разрешению.

Пять новых локальных тестов: неактивная страница; скрытый/недоступный родитель и unknown-видимость; неполнота/дубликаты; чтение скрытого элемента без разрешения click; неверный тип страницы. Старые принятые наборы и сборка не повторялись. AST, OpenSpec strict и diff-check выполнены.

# TASK-021 — новые capabilities через file и embedded

17.11.2026. Проверен оставшийся маршрутный охват [семи новых capabilities](scenario-capabilities-expansion.md) на отдельных файловых базах **8.5.1.1529**, с видимым тест-клиентом. HTTP и прежние наборы не повторялись.

| Маршрут | Новые сценарии | Шаги | Проверки |
|---|---|---|---|
| Файловый мост | window-observations, checkbox-button | 9/9 | 7/7 |
| Embedded HTTP | window-observations, checkbox-button | 9/9 | 7/7 |

Оба сценария запускаются самостоятельными процессами продуктового CLI, с контекстом из живого сеанса и отдельной политикой точных команд. Проверены activate_window, expect title/visible/enabled/read_only, check=true/false, click/button и чтение счётчика=1. Каждый шаг имеет свой operation_id, по девять уникальных ID на маршрут; dispatch_count равен числу шагов. Предусмотрены четыре изменяющих шага: активация, установка флажка, одно нажатие, снятие флажка. В файловом общем lifecycle дополнительно read-only подтверждены ровно четыре соответствующие succeeded-операции. Для embedded основание — ответы общего lifecycle и счётчик формы; отдельный SQLite-журнал ему не приписывается.

Счётчик кнопки равен 1, флажок возвращён в исходное состояние, документы до/после совпадают. Все собственные процессы обоих стендов завершены. Отдельного повтора мутаций нет. Поддержка активации остаётся ограничена видимым клиентом; положительный результат не отменяет прежний action_not_confirmed в скрытом клиенте.

## Изменения и проверки

В продуктовых записях семи capabilities добавлены file-file и file-embedded. **Теперь по 12 ключей для HTTP, файлового моста и embedded**, только для файловой 8.5.1.1529. Неизвестный маршрут остаётся без capabilities. Проверен один изменённый локальный тест маршрутов, а не весь прежний набор. Исполнитель/поставщик, BSL и EPF не менялись; повторная сборка не требовалась. Сохранены исходные ответы, контексты, планы, ID, cleanup и хеши.

[Сводка](evidence/scenario-capabilities-routes/summary.json), [хеши и доказательства](evidence/scenario-capabilities-routes/sha256.json).

Пробел этих двух маршрутов снят. Другие capabilities, таблицы, группы-карточки, клиент-серверная база и другие платформы не объявлены поддержанными. Наблюдатель не подключён, анонимизация отложена, Открыть() не исследовалось, рабочая установка не обновлялась. Пункты остаются открытыми, 13/42; актуальный объём отражён в [едином остатке TASK-021](task021-remainder.md).
